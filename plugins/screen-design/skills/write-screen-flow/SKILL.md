# /write-screen-flow — 画面遷移図の作成

`/write-screen-spec` で書いた画面設計書から、「どの画面の、どのボタンやリンクから、どの画面へ移るか」を 1 枚で見渡せる画面遷移図を、draw.io のファイルとして作る。

以下の相対パスは、この SKILL.md があるディレクトリを起点にする。

- 描き方の決まり: [references/flow-rules.md](references/flow-rules.md)
- サンプル: [../../examples/docs/screens/screen-flow.drawio](../../examples/docs/screens/screen-flow.drawio)（同じ場所の設計書から作ったもの。形・スタイル・ID・配置は、これに合わせる）

## 手順

1. **入力を集める**: `overview.md` のある場所を探し、画面一覧と、すべての画面設計書（廃止を除く）を読む。決まりとサンプルを読む。`screen-flow.drawio` がすでにあれば読み、更新として進める。
2. **遷移を洗い出して見せる**: 図を描く前に、設計書から拾った遷移（遷移元、きっかけ、遷移先、開き方）を表にして見せる。メモにまとめるもの、外部として描くもの、設計書があいまいで遷移先を決めきれないものも伝える。図を描いてから直すより早いため。
3. **図を描く**: 保存先の `screen-flow.drawio` に書く。すでにあるときは、決まりの「更新するとき」に従う。`overview.md` の冒頭の表に、このファイルの行がなければ足す。
4. **確かめる**: 決まりの「描き終えたら確かめること」を行う。ブラウザを操作するツールが使え、ユーザーが外部のサイトで開くことを了承したときは、draw.io のビューアで開いて、重なりがないかを見る。そうでなければ、報告で未実施と伝える。
5. **報告**: 作ったファイルと開き方、画面と遷移の数、メモにまとめたもの、更新で足した・消した・残した部品、設計書に反映したほうがよい点。コミットはしない。
