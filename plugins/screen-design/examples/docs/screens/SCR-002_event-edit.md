## 1. 概要

イベントを新規作成する、または既存のイベントを編集・削除する画面。下書きとして保存しておき、準備ができたら公開する。

## 2. クエリパラメータ

なし

## 3. 権限

| 利用者の種類 | 閲覧 | 備考 |
| --- | --- | --- |
| admin | ○ | すべてのイベントを編集・削除できる |
| organizer | ○ | 編集・削除は自分が主催のイベントだけ。他の人のイベントを開くと API が 403 を返す |
| member | × | MSG-020 をトーストで表示して SCR-001 イベント一覧へ遷移する |
| 未ログイン | × | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |

## 5. 初期表示時の処理

1. フォームの代わりにスピナーを表示する。
2. `GET /me`（operationId: `getMe`）を呼ぶ。

   リクエスト: なし

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | `id` と `role` を画面の表示条件の判定用に保持する |
   | 401 | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |
   | 上記以外 | スピナーを消す<br>MSG-022 を No.6 に表示して終了する |

3. `role` が `member` のとき、MSG-020 をトーストで表示する。
4. `role` が `member` のとき、SCR-001 イベント一覧へ遷移して終了する。
5. URL パラメータ `eventId` があれば編集、なければ新規作成として扱う。
6. `GET /categories`（operationId: `listCategories`）を呼ぶ。

   リクエスト: なし

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | `items[]` を No.11 の選択肢にする（表示は `name`、値は `id`。先頭に「選択してください」を置く） |
   | 401 | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |
   | 上記以外 | スピナーを消す<br>MSG-022 を No.6 に表示して終了する |

7. 新規作成のとき、各入力項目に新規の初期値を入れる。
8. 新規作成のとき、スピナーを消す。
9. 新規作成のとき、フォームを表示して終了する。
10. `GET /events/{eventId}`（operationId: `getEvent`）を呼ぶ。

    リクエスト

    | 場所 | パラメータ | 値 |
    | --- | --- | --- |
    | path | `eventId` | URL パラメータ `eventId` |

    レスポンス

    | ステータス | 処理 |
    | --- | --- |
    | 200 | 各入力項目に編集の初期値を入れる<br>`status` を No.4 に、`organizerName` を No.5 に表示する<br>`version`、`status`、`participantCount`、`organizerId` を保持する<br>スピナーを消す<br>フォームを表示する |
    | 401 | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |
    | 403 | MSG-020 をトーストで表示する<br>SCR-001 イベント一覧へ遷移する |
    | 404 | MSG-021 をトーストで表示する<br>SCR-001 イベント一覧へ遷移する |
    | 上記以外 | スピナーを消す<br>MSG-022 を No.6 に表示する |

1. 入力内容に変更がないとき、SCR-001 イベント一覧へ遷移して終了する。

5. 非表示にした項目の入力済みの値は残す（選び直したときに戻せるようにするため）。

   | body | `status` | 保持した `status` が `draft` なら固定値 `published`、それ以外は保持した `status` |
   | body | `version` | 初期表示で保持した `version` |
   | body | `notifyParticipants` | No.24 のチェック状態（No.24 が表示されていないときは送らない） |

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | 保持した `status` が `draft` だったら MSG-014、それ以外は MSG-015 をトーストで表示する<br>SCR-001 イベント一覧へ遷移する |
   | 401 | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |
   | 403 | MSG-020 をトーストで表示する |
   | 404 | MSG-021 をトーストで表示する<br>SCR-001 イベント一覧へ遷移する |
   | 409 | MSG-018 を No.6 に表示する |
   | 422 | `errors[]` を A6 の「422 の表示先」のとおりに表示する<br>最初のエラー項目までスクロールする |
   | 上記以外 | MSG-022 を No.6 に表示する |

6. 画面に残っているとき、No.25〜27 の非活性を解除する（活性条件に従う状態に戻す）。

   レスポンス
