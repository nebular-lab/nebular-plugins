# SCR-002 イベント編集

| 項目 | 内容 |
| --- | --- |
| 画面 ID | SCR-002 |
| 画面名 | イベント編集 |
| URL | `/events/new`（新規作成）<br>`/events/{eventId}/edit`（編集） |
| ワイヤーフレーム | [SCR-002_event-edit.html](SCR-002_event-edit.html) |
| API 定義 | [openapi.yaml](../api/openapi.yaml) |
| 更新日 | 2026-09-26 |

## 1. 概要

イベントを新規作成する、または既存のイベントを編集・削除する画面。下書きとして保存しておき、準備ができたら公開する。

## 2. 権限

| 利用者の種類 | 閲覧 | 備考 |
| --- | --- | --- |
| admin | ○ | すべてのイベントを編集・削除できる |
| organizer | ○ | 編集・削除は自分が主催のイベントだけ。他の人のイベントを開くと API が 403 を返す |
| member | × | M24 を表示して SCR-001 イベント一覧へ遷移する |
| 未ログイン | × | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |

## 4. 初期表示時の処理

1. フォームの代わりにスピナーを表示する。
2. `GET /me`（operationId: `getMe`）を呼ぶ。

   リクエスト: なし

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | `id` と `role` を画面の表示条件の判定用に保持する |
   | 401 | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |
   | 上記以外 | スピナーを消す<br>M26 を表示して終了する |

3. `role` が `member` のとき、M24 を表示する。
4. `role` が `member` のとき、SCR-001 イベント一覧へ遷移して終了する。
5. URL パラメータ `eventId` があれば編集、なければ新規作成として扱う。
6. `GET /categories`（operationId: `listCategories`）を呼ぶ。

   リクエスト: なし

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | `items[]` を No.8 の選択肢にする |
   | 401 | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |
   | 上記以外 | スピナーを消す<br>M26 を表示して終了する |

7. 新規作成のとき、各入力項目に新規の初期値を入れる。
8. 新規作成のとき、スピナーを消す。
9. 新規作成のとき、フォームを表示して終了する。
10. `GET /events/{eventId}`（operationId: `getEvent`）を呼ぶ。

   リクエスト

   | 場所 | パラメータ | 値 |
   | --- | --- | --- |
   | path | `eventId` | URL パラメータ `eventId` |

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | 各入力項目に編集の初期値を入れる<br>`status` を No.4 に、`organizerName` を No.5 に表示する<br>`version`、`status`、`participantCount`、`organizerId` を保持する<br>スピナーを消す<br>フォームを表示する |
   | 401 | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |
   | 403 | M24 を表示する<br>SCR-001 イベント一覧へ遷移する |
   | 404 | M25 を表示する<br>SCR-001 イベント一覧へ遷移する |
   | 上記以外 | スピナーを消す<br>M26 を表示する |

### A1. No.6 からフォーカスが外れる

1. 入力チェックを行う。

### A2. 開催形式の選択を変更

1. 「会場」を選んだなら No.10 を表示する。なければ No.10 を非表示にする。
2. 「オンライン」を選んだなら No.11 を表示する。なければ No.11 を非表示にする。
3. 非表示にした項目の入力値は消さずに残す（選び直したときに戻せるようにするため）。

### A3. No.13 に入力

1. 入力チェックを行う。

   | No | 項目 | 条件 | メッセージ |

   | 13 | 定員 | 範囲 | M14 |
   | 13 | 定員 | 参加者数以上（編集時だけ。`participantCount` より小さいとエラー） | M15 |

2. エラーがあれば、No.13 の下に最初の 1 件を表示する。なければ No.13 のエラー表示を消す。

### A4. タグの選択を変更

1. 選んだ数が 3 を超えたとき、今選んだチェックを外す。
2. 同じ条件のとき、M16 を No.14 の下に表示する。

### A6. 「公開する」／「更新する」ボタン押下

   | 上記以外 | M26 を表示する |

   リクエスト
