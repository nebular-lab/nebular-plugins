# 共通ルール

どの画面でも同じになる扱い。画面設計書は、このルールに従って書く。ある画面だけ違う扱いにするときは、その画面の設計書に書く。

## 入力

| 項目 | 設定 | 選択肢 |
| --- | --- | --- |
| 改行を 1 文字と数えるか | yes | `yes` / `no` |
| 文字数のバリデーション時に前後の空白を取り除くか | yes | `yes` / `no` |
| 送信時に前後の空白を取り除くか | yes | `yes` / `no` |
| 入力可能文字種・`maxlength` のある項目への貼り付け | 収める | `収める` / `受け付けない` |
| 日本語入力（IME）の変換を確定する前の文字にも、入力の制限とバリデーションを行うか | no | `yes` / `no` |

## 表示形式

| 項目 | 設定 | 選択肢 |
| --- | --- | --- |
| 数値を 3 桁ごとにカンマで区切るか | yes | `yes` / `no` |

## 一覧

| 項目 | 設定 | 選択肢 |
| --- | --- | --- |
| 再読み込みやブラウザの戻るで一覧に戻ったときに、検索条件とページを復元するか | yes | `yes` / `no` |

## 送信

| 項目 | 設定 | 選択肢 |
| --- | --- | --- |
| 送信中にボタンを非活性にするか | yes | `yes` / `no` |

## 通信

| 項目 | 設定 | 選択肢 |
| --- | --- | --- |
| フロントエンドで、応答を待つ時間に上限を設けるか | 設けない（インフラのタイムアウトに任せる） | `設けない（インフラのタイムアウトに任せる）` / 秒数 |
| 応答を待つのをやめたとき | レスポンスの「上記以外」と同じに扱う | `レスポンスの「上記以外」と同じに扱う` / `やり直すかどうかを利用者に聞く` |

## メッセージ

| 項目 | 設定 | 選択肢 |
| --- | --- | --- |
| トーストが表示されている間に、次のトーストを表示するとき | 前のトーストを消して、新しいものだけを表示する | `前のトーストを消して、新しいものだけを表示する` / `前のトーストを残したまま、並べて表示する` |

## 遷移

| 項目 | 設定 | 選択肢 |
| --- | --- | --- |
| ブラウザの戻るで画面に戻ったときに、スクロール位置を復元するか | yes | `yes` / `no` |
| ブラウザの戻るで画面に戻ったときに、入力内容を復元するか | no | `yes` / `no` |
| 未保存の変更があるときに離脱確認をするか | yes | `yes` / `no` |

## アクセシビリティ

次のルールは、選択肢なしで、すべての画面に適用する。

- 入力項目のエラー表示の内容は、その入力項目の説明として伝える（その入力項目にフォーカスしたときに、エラーの内容も読み上げられる）。
- 入力項目に結び付かないエラー表示（画面上部のエラーなど）を表示したときは、読み上げで通知する。
- トーストを表示したときは、読み上げで通知する。
- 送信時にエラーがあるときは、最初のエラー項目にフォーカスを移す。
- 確認ダイアログを開いたときは、フォーカスをダイアログの中の最初のボタンに移す。
- 確認ダイアログを閉じたときは、そのダイアログを開いたボタン・リンクにフォーカスを戻す。
- 確認ダイアログは Esc キーで閉じられる。やめる側のボタン（「キャンセル」など）を押したときと同じ処理をする。
- 一覧を取り直したとき（検索、ページ送りなど）は、結果（件数、または 0 件のときの文言）を読み上げで通知する。
- Tab キーでフォーカスが移る順序は、部品番号の順にする。
- 文言のない部品（アイコンだけのボタン、画像）には、読み上げ名を付ける。

## react-hook-form のデフォルト設定

対象のバージョン: react-hook-form v7。`useForm` に渡す設定。

| 項目 | 設定 | ライブラリの既定値 | 選択肢 |
| --- | --- | --- | --- |
| `mode` | onSubmit | onSubmit | `onChange` / `onBlur` / `onSubmit` / `onTouched` / `all` |
| `reValidateMode` | onSubmit | onChange | `onChange` / `onBlur` / `onSubmit` |

## TanStack Query の設定（defaultOptions）

対象のバージョン: TanStack Query v5（`@tanstack/react-query`）。`QueryClient` の `defaultOptions` に渡す設定。

| 項目 | 設定 | ライブラリの既定値 | 選択肢 |
| --- | --- | --- | --- |
| queries の `staleTime` | 0 | 0 | `0` / `Infinity` / ミリ秒の数値 |
| queries の `gcTime` | 300000 | 300000（5 分） | ミリ秒の数値 / `Infinity` |
| queries の `refetchOnMount` | true | true | `true` / `false` / `'always'` |
| queries の `refetchOnWindowFocus` | false | true | `true` / `false` / `'always'` |
| queries の `refetchOnReconnect` | false | true | `true` / `false` / `'always'` |
| queries の `retry` | false | 3 | `false` / 回数 |
| mutations の `retry` | false | 0 | `false` / 回数 |
