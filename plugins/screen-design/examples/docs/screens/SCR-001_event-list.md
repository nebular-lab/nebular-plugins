## 1. 概要

イベントをキーワードとステータスで探す画面。タイトルからイベントの詳細に進む。admin と organizer は、ここからイベントの作成にも進む。

## 2. クエリパラメータ

| パラメータ | 値 | 省略したとき | 用途 |
| --- | --- | --- | --- |
| `keyword` | 文字列 | 空 | キーワードの初期値と、検索の条件（`GET /events` の `keyword`）。前後の空白は除いて使う。空白を除いて空になるときは、省略したときと同じに扱う |
| `status` | `published`、`draft`、`closed` | 「すべて」のタブを選ぶ | 選ぶタブと、検索の条件（`GET /events` の `status`）。この 3 つ以外の値のとき、または `GET /me` の `role` が `member` で `draft` のときは、省略したときと同じに扱う |
| `page` | 1 以上の整数 | 1 | 表示するページ（`GET /events` の `page`）。1 以上の整数でない値のときは、省略したときと同じに扱う。総ページ数を超える値は、そのまま使う（一覧は 0 件になり、データなしの表示とページ送りを表示する） |

## 5. 初期表示時の処理

1. `GET /me`（operationId: `getMe`）を呼ぶ。

   リクエスト: なし

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | `name` を No.2 に表示する<br>`id` と `role` を画面の表示条件の判定用に保持する |
   | 401 | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |
   | 上記以外 | MSG-023 を No.30 に表示して終了する（No.6〜10 は表示したままにする） |

2. URL クエリ `keyword` を No.7 に入れる（前後の空白は除く）。
3. URL クエリ `status` に対応するタブを No.10 で選ぶ。「2. クエリパラメータ」で省略したときと同じに扱う場合は、「すべて」を選ぶ。
4. No.5、No.11、No.22、No.29、No.30 を非表示にする。
5. 一覧の位置に No.28 を表示する。
6. `GET /events`（operationId: `listEvents`）を呼ぶ。

   リクエスト

   | 場所 | パラメータ | 値 |
   | --- | --- | --- |
   | query | `keyword` | URL クエリ `keyword`（前後の空白を除く。省略したときと同じに扱う場合は送らない） |
   | query | `status` | URL クエリ `status`（省略したときと同じに扱う場合は送らない） |
   | query | `page` | URL クエリ `page`（省略したときと同じに扱う場合は固定値 1） |
   | query | `perPage` | 固定値 20 |

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | No.28 を非表示にする<br>`items` が 0 件なら No.29 を表示する<br>`items` が 1 件以上なら `items[]` を No.11 に入れて表示する<br>`total` が 1 件以上なら `total`、`page`、`perPage` から No.22 を表示する |
   | 400 | No.28 を非表示にする<br>MSG-024 を No.5 に表示する |
   | 401 | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |
   | 上記以外 | No.28 を非表示にする<br>MSG-023 を No.30 に表示する |

## 6. アクション

### アクション一覧

| ID | 操作 | 対象 | 概要 |
| --- | --- | --- | --- |
| A1 | 「イベントを作成」ボタン押下 | No.4 | イベントの作成へ移る |
| A2 | 「検索」ボタン押下 | No.9 | キーワードで検索し直す |
| A3 | タブの切り替え | No.10 | 選んだステータスで検索し直す |
| A4 | タイトルのリンク押下 | No.17 | イベントの詳細へ移る |
| A5 | 「オンライン会場」リンク押下 | No.21 | 配信 URL を別タブで開く |
| A6 | 「前へ」ボタン押下 | No.23 | 前のページを表示する |
| A7 | 「次へ」ボタン押下 | No.25 | 次のページを表示する |
| A8 | 「ヘルプ」リンク押下 | No.27 | ヘルプを別タブで開く |
| A9 | 「再読み込み」ボタン押下 | No.31 | 一覧を読み込み直す |

### A1. 「イベントを作成」ボタン押下

1. SCR-004 イベント作成へ遷移する。

### A2. 「検索」ボタン押下

1. バリデーションを行う。

   | No | 項目 | 条件 | メッセージ | 表示先 |
   | --- | --- | --- | --- | --- |
   | 7 | キーワード | 50 文字以内 | MSG-004（v1: キーワード、v2: 50） | No.8 |
   | 7 | キーワード | 使える文字: 全角文字（ひらがな・カタカナ・漢字・英数字・記号）、半角英数字、半角記号 | MSG-005（v1: キーワード） | No.8 |

2. エラーがあれば、No.8 に最初の 1 件を表示して終了する。なければ No.8 を非表示にする。
3. No.9 を非活性にする。
4. URL クエリの `keyword` を No.7 の入力値（前後の空白を除く。空なら `keyword` を消す）に、`page` を 1 に書き換える（ブラウザの履歴に追加する）。`status` は変えない。
5. 「5. 初期表示時の処理」の手順 4〜6 と同じく `GET /events` を呼ぶ（`keyword` と `page` は手順 4 で書き換えた値になる）。
6. No.9 の非活性を解除する。

### A3. タブの切り替え

1. 選んだタブを選択状態にする。
2. URL クエリの `status` を選んだタブの値（「公開中」は `published`、「下書き」は `draft`、「終了」は `closed`。「すべて」なら `status` を消す）に、`page` を 1 に書き換える（ブラウザの履歴に追加する）。`keyword` は変えない（No.7 に入力途中の値があっても、検索には使わない）。
3. 「5. 初期表示時の処理」の手順 4〜6 と同じく `GET /events` を呼ぶ（`status` と `page` は手順 2 で書き換えた値になる）。

### A4. タイトルのリンク押下

1. SCR-003 イベント詳細へ遷移する（`eventId` に、押した行の `GET /events` の `items[].id` を渡す）。

### A5. 「オンライン会場」リンク押下

1. 押した行の `GET /events` の `items[].onlineUrl` を別タブで開く。

### A6. 「前へ」ボタン押下

1. URL クエリの `page` を 1 減らす（ブラウザの履歴に追加する）。
2. 「5. 初期表示時の処理」の手順 4〜6 と同じく `GET /events` を呼ぶ（`page` は手順 1 で書き換えた値になる）。
3. 画面の一番上までスクロールする。

### A7. 「次へ」ボタン押下

1. URL クエリの `page` を 1 増やす（ブラウザの履歴に追加する）。
2. 「5. 初期表示時の処理」の手順 4〜6 と同じく `GET /events` を呼ぶ（`page` は手順 1 で書き換えた値になる）。
3. 画面の一番上までスクロールする。

### A8. 「ヘルプ」リンク押下

1. ヘルプ（URL は TBD）を別タブで開く。

### A9. 「再読み込み」ボタン押下

1. `GET /me` が失敗していたなら「5. 初期表示時の処理」の手順 1〜6 をやり直す。なければ手順 4〜6 と同じく `GET /events` を呼ぶ。
