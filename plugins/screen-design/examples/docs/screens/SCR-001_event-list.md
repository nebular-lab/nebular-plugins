## 1. 概要

イベントをキーワードとステータスで探す画面。admin と organizer はここからイベントの作成・編集に進む。

## 2. 権限

| 利用者の種類 | 閲覧 | 備考 |
| --- | --- | --- |
| admin | ○ | - |
| organizer | ○ | - |
| member | ○ | 「イベントを作成」と「下書き」タブは表示しない |
| 未ログイン | × | ログイン画面（`/login?redirect=/events`）へ遷移する |

## 4. 初期表示時の処理

1. `GET /me`（operationId: `getMe`）を呼ぶ。

   リクエスト: なし

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | `name` を No.2 に表示する<br>`id` と `role` を画面の表示条件の判定用に保持する |
   | 401 | ログイン画面（`/login?redirect=/events`）へ遷移する |
   | 上記以外 | 一覧の位置に No.22 を表示して終了する |

2. URL クエリ `keyword` を No.5 に入れる。
3. URL クエリ `status` に対応するタブを No.7 で選ぶ。`status` がないとき、または `role` が `member` で `status` が `draft` のときは「すべて」を選ぶ。
4. No.8、No.14、No.21、No.22 を非表示にする。
5. 一覧の位置に No.20 を表示する。
6. `GET /events`（operationId: `listEvents`）を呼ぶ。

   リクエスト

   | 場所 | パラメータ | 値 |
   | --- | --- | --- |
   | query | `keyword` | No.5 の入力値（前後の空白を除く。空なら送らない） |
   | query | `status` | No.7 で選んだタブ（「公開中」は `published`、「下書き」は `draft`、「終了」は `closed`。「すべて」なら送らない） |
   | query | `page` | URL クエリ `page`（なければ固定値 1） |
   | query | `perPage` | 固定値 20 |

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | No.20 を非表示にする<br>`items` が 0 件なら No.21 を表示する<br>`items` が 1 件以上なら `items[]` を No.8 に入れて表示する<br>`items` が 1 件以上なら `total`、`page`、`perPage` から No.14 を表示する |
   | 400 | No.20 を非表示にする<br>M4 を表示する |
   | 401 | ログイン画面（`/login?redirect=/events`）へ遷移する |
   | 上記以外 | No.20 を非表示にする<br>一覧の位置に No.22 を表示する |

## 5. アクション

### アクション一覧

| ID | 操作 | 対象 | 概要 |
| --- | --- | --- | --- |
| A1 | 「検索」ボタン押下、または No.5 で Enter キー押下 | No.6<br>No.5 | キーワードで検索し直す |
| A2 | タブの切り替え | No.7 | 選んだステータスで検索し直す |
| A3 | 「前へ」ボタン押下 | No.15 | 前のページを表示する |
| A4 | 「次へ」ボタン押下 | No.17 | 次のページを表示する |
| A5 | 「再読み込み」ボタン押下 | No.23 | 一覧を読み込み直す |

### A1. 「検索」ボタン押下、または No.5 で Enter キー押下

1. 入力チェックを行う。

   | No | 項目 | 条件 | メッセージ |
   | --- | --- | --- | --- |
   | 5 | キーワード | 最大文字数 | M1 |
   | 5 | キーワード | 使用できる文字種 | M2 |

2. エラーがあれば、No.5 の下に最初の 1 件を表示して終了する。なければ No.5 のエラー表示を消す。
3. URL クエリの `keyword` を No.5 の入力値に、`page` を 1 に書き換える（ブラウザの履歴に追加する）。
4. 「4. 初期表示時の処理」の手順 4〜6 と同じく `GET /events` を呼ぶ。ただし `page` は固定値 1 にする。

### A2. タブの切り替え

1. 選んだタブを選択状態にする。
2. URL クエリの `status` を選んだタブに、`page` を 1 に書き換える（ブラウザの履歴に追加する）。
3. 「4. 初期表示時の処理」の手順 4〜6 と同じく `GET /events` を呼ぶ。ただし `page` は固定値 1 にする。

### A3. 「前へ」ボタン押下

1. URL クエリの `page` を 1 減らす（ブラウザの履歴に追加する）。
2. 「4. 初期表示時の処理」の手順 4〜6 と同じく `GET /events` を呼ぶ。ただし `page` は現在の `page` から 1 引いた値にする。
3. 画面の一番上までスクロールする。

### A4. 「次へ」ボタン押下

1. URL クエリの `page` を 1 増やす（ブラウザの履歴に追加する）。
2. 「4. 初期表示時の処理」の手順 4〜6 と同じく `GET /events` を呼ぶ。ただし `page` は現在の `page` に 1 足した値にする。
3. 画面の一番上までスクロールする。

### A5. 「再読み込み」ボタン押下

1. `GET /me` が失敗していたなら「4. 初期表示時の処理」の手順 1〜6 をやり直す。なければ手順 4〜6 と同じく `GET /events` を呼ぶ。

## 6. メッセージ

| ID | 種別 | 文言 | 表示場所 |
| --- | --- | --- | --- |
| M1 | エラー | キーワードは 50 文字以内で入力してください | 項目の下 |
| M2 | エラー | キーワードに使えない文字（絵文字など）が含まれています | 項目の下 |
| M3 | エラー | イベントを読み込めませんでした。 | No.22 の中 |
| M4 | エラー | 検索条件が正しくありません。条件を変えて検索してください | 画面上部 |
