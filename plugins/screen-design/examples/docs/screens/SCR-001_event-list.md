## 1. 概要

イベントをキーワードとステータスで探す画面。admin と organizer はここからイベントの作成・編集に進む。

## 2. クエリパラメータ

| パラメータ | 値 | 省略したとき | 用途 |
| --- | --- | --- | --- |
| `keyword` | 文字列 | 空 | キーワードの初期値と、検索の条件 |
| `status` | `published`、`draft`、`closed` | 「すべて」のタブを選ぶ | 選ぶタブと、検索の条件。`member` で `draft` が指定されたときは、省略したときと同じに扱う |
| `page` | 1 以上の整数 | 1 | 表示するページ |

## 3. 権限

| 利用者の種類 | 閲覧 | 備考 |
| --- | --- | --- |
| admin | ○ | - |
| organizer | ○ | - |
| member | ○ | 「イベントを作成」と「下書き」タブは表示しない |
| 未ログイン | × | ログイン画面（`/login?redirect=/events`）へ遷移する |

## 5. 初期表示時の処理

1. `GET /me`（operationId: `getMe`）を呼ぶ。

   リクエスト: なし

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | `name` を No.2 に表示する<br>`id` と `role` を画面の表示条件の判定用に保持する |
   | 401 | ログイン画面（`/login?redirect=/events`）へ遷移する |
   | 上記以外 | MSG-023 を No.24 に表示して終了する |

2. URL クエリ `keyword` を No.6 に入れる。
3. URL クエリ `status` に対応するタブを No.9 で選ぶ。`status` がないとき、または `role` が `member` で `status` が `draft` のときは「すべて」を選ぶ。
4. No.5、No.10、No.16、No.23、No.24 を非表示にする。
5. 一覧の位置に No.22 を表示する。
6. `GET /events`（operationId: `listEvents`）を呼ぶ。

   リクエスト

   | 場所 | パラメータ | 値 |
   | --- | --- | --- |
   | query | `keyword` | No.6 の入力値（前後の空白を除く。空なら送らない） |
   | query | `status` | No.9 で選んだタブ（「公開中」は `published`、「下書き」は `draft`、「終了」は `closed`。「すべて」なら送らない） |
   | query | `page` | URL クエリ `page`（なければ固定値 1） |
   | query | `perPage` | 固定値 20 |

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | No.22 を非表示にする<br>`items` が 0 件なら No.23 を表示する<br>`items` が 1 件以上なら `items[]` を No.10 に入れて表示する<br>`items` が 1 件以上なら `total`、`page`、`perPage` から No.16 を表示する |
   | 400 | No.22 を非表示にする<br>MSG-024 を No.5 に表示する |
   | 401 | ログイン画面（`/login?redirect=/events`）へ遷移する |
   | 上記以外 | No.22 を非表示にする<br>MSG-023 を No.24 に表示する |

## 6. アクション

### アクション一覧

| ID | 操作 | 対象 | 概要 |
| --- | --- | --- | --- |
| A1 | 「イベントを作成」ボタン押下 | No.4 | イベントの新規作成へ移る |
| A2 | 「検索」ボタン押下 | No.8 | キーワードで検索し直す |
| A3 | タブの切り替え | No.9 | 選んだステータスで検索し直す |
| A4 | タイトルのリンク押下 | No.11 | イベントの編集へ移る |
| A5 | 「オンライン会場」リンク押下 | No.15 | 配信 URL を別タブで開く |
| A6 | 「前へ」ボタン押下 | No.17 | 前のページを表示する |
| A7 | 「次へ」ボタン押下 | No.19 | 次のページを表示する |
| A8 | 「ヘルプ」リンク押下 | No.21 | ヘルプを別タブで開く |
| A9 | 「再読み込み」ボタン押下 | No.25 | 一覧を読み込み直す |

### A1. 「イベントを作成」ボタン押下

1. SCR-002 イベント編集（新規作成。`/events/new`）へ遷移する。

### A2. 「検索」ボタン押下

1. バリデーションを行う。

   | No | 項目 | 条件 | メッセージ | 表示先 |
   | --- | --- | --- | --- | --- |
   | 6 | キーワード | 50 文字以内 | MSG-004（v1: キーワード、v2: 50） | No.7 |
   | 6 | キーワード | 使える文字: 全角文字（ひらがな・カタカナ・漢字・英数字・記号）、半角英数字、半角記号 | MSG-005（v1: キーワード） | No.7 |

2. エラーがあれば、No.7 に最初の 1 件を表示して終了する。なければ No.7 を非表示にする。
3. No.8 を非活性にする。
4. URL クエリの `keyword` を No.6 の入力値に、`page` を 1 に書き換える（ブラウザの履歴に追加する）。
5. 「5. 初期表示時の処理」の手順 4〜6 と同じく `GET /events` を呼ぶ。ただし `page` は固定値 1 にする。
6. No.8 の非活性を解除する。

### A3. タブの切り替え

1. 選んだタブを選択状態にする。
2. URL クエリの `status` を選んだタブに、`page` を 1 に書き換える（ブラウザの履歴に追加する）。
3. 「5. 初期表示時の処理」の手順 4〜6 と同じく `GET /events` を呼ぶ。ただし `page` は固定値 1 にする。

### A4. タイトルのリンク押下

1. SCR-002 イベント編集へ遷移する（`eventId` に `items[].id` を渡す）。

### A5. 「オンライン会場」リンク押下

1. `items[].onlineUrl` を別タブで開く。

### A6. 「前へ」ボタン押下

1. URL クエリの `page` を 1 減らす（ブラウザの履歴に追加する）。
2. 「5. 初期表示時の処理」の手順 4〜6 と同じく `GET /events` を呼ぶ（`page` は手順 1 で書き換えた値になる）。
3. 画面の一番上までスクロールする。

### A7. 「次へ」ボタン押下

1. URL クエリの `page` を 1 増やす（ブラウザの履歴に追加する）。
2. 「5. 初期表示時の処理」の手順 4〜6 と同じく `GET /events` を呼ぶ（`page` は手順 1 で書き換えた値になる）。
3. 画面の一番上までスクロールする。

### A8. 「ヘルプ」リンク押下

1. ヘルプ（URL は TBD）を別タブで開く。

### A9. 「再読み込み」ボタン押下

1. `GET /me` が失敗していたなら「5. 初期表示時の処理」の手順 1〜6 をやり直す。なければ手順 4〜6 と同じく `GET /events` を呼ぶ。
