# HDR-001 ログイン後のヘッダー

| 項目 | 内容 |
| --- | --- |
| ヘッダー ID | HDR-001 |
| ヘッダー名 | ログイン後のヘッダー |
| 使う画面 | ログインして使う画面（どの画面で使っているかは、[overview.md](../overview.md) の画面一覧を見る） |
| ワイヤーフレーム | [HDR-001_app-header.html](HDR-001_app-header.html) |
| 更新日 | 2026-10-11 |

## 1. 概要

ログインした利用者が使う画面の、いちばん上に置くヘッダー。いまの画面の名前と、ログイン中のユーザーを表示し、全画面で共通のメニューを開く。

## 2. 変数

ヘッダーを置く画面が、設計書の冒頭の表の「共通ヘッダー」で値を指定する。

| 変数 | 内容 |
| --- | --- |
| `{v1}` | いまの画面の名前（その画面の設計書の「画面名」） |

## 4. 初期表示時の処理

なし。ヘッダーからは API を呼ばない。No.6 に表示する `GET /me` の値は、ヘッダーを置く画面が、初期表示時の処理で取ったものを使う。
