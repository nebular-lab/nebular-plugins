## 1. 概要

すでにあるイベントの内容を直す画面。下書きを公開する、公開中の内容を更新する、イベントを削除する、のどれかを行う。

## 2. クエリパラメータ

なし

## 3. 権限

| 利用者の種類 | 閲覧 | 備考 |
| --- | --- | --- |
| admin | ○ | すべてのイベントを編集・削除できる |
| organizer | ○ | 編集・削除は自分が主催のイベントだけ。他の人のイベントを開くと API が 403 を返す |
| member | × | MSG-020 をトーストで表示して SCR-001 イベント一覧へ遷移する |
| 未ログイン | × | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |

### A1. 「← 一覧へ戻る」リンク押下

1. 入力内容に変更がないとき（どの入力項目も、基準の値と同じとき。基準は、初期表示のときの値。下書き保存に成功したあとは、最後に成功した保存を始めたとき（ボタンを押したとき）の入力欄の値）、SCR-001 イベント一覧へ遷移して終了する。
2. No.41 を表示する。

### A2. No.9 からフォーカスが外れる

1. バリデーションを行う。

   | No | 項目 | 条件 | メッセージ | 表示先 |
   | --- | --- | --- | --- | --- |
   | 9 | タイトル | 必須 | MSG-001（v1: タイトル） | No.10 |
   | 9 | タイトル | 2 文字以上 | MSG-003（v1: タイトル、v2: 2） | No.10 |
   | 9 | タイトル | 50 文字以内 | MSG-004（v1: タイトル、v2: 50） | No.10 |
   | 9 | タイトル | 使える文字: 全角文字（ひらがな・カタカナ・漢字・英数字・記号）、半角英数字、半角記号 | MSG-005（v1: タイトル） | No.10 |

2. エラーがあれば、No.10 に最初の 1 件を表示する。なければ No.10 を非表示にする。

### A3. 開催形式の選択を変更

1. 「会場」を選んだとき、No.20 を表示する。
2. 「会場」を選んだとき、No.23 と No.24 を非表示にする。
3. 「オンライン」を選んだとき、No.23 を表示する。
4. 「オンライン」を選んだとき、No.20 と No.21 を非表示にする。
5. 非表示にした項目の入力済みの値は残す（選び直したときに戻せるようにするため）。
6. 選び直して表示した項目のエラー表示は、非表示のままにする（その項目を次にチェックするまで出さない）。

   | body | `version` | 保持している `version`（初期表示で保持した値。下書き保存に成功したあとは、保持し直した値） |
   | body | `notifyParticipants` | No.34 のチェック状態（No.34 が表示されていないときは送らない） |

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | 保持した `status` が `draft` だったら MSG-014、それ以外は MSG-015 をトーストで表示する<br>SCR-001 イベント一覧へ遷移する |
   | 401 | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |
   | 403 | MSG-020 をトーストで表示する |
   | 404 | MSG-021 をトーストで表示する<br>SCR-001 イベント一覧へ遷移する |
   | 409 | MSG-018 を No.7 に表示する |
   | 422 | `errors[]` を A6 の「422 の表示先」のとおりに表示する<br>最初のエラー項目までスクロールする |
   | 上記以外 | MSG-022 を No.7 に表示する |

5. 画面に残っているとき、No.35〜37 の非活性を解除する（活性条件に従う状態に戻す）。

### A8. 「削除」ボタン押下

1. No.38 を表示する。

### A9. 削除の確認で「キャンセル」ボタン押下

### A10. 削除の確認で「削除する」ボタン押下

2. No.40 を非活性にする。
3. `DELETE /events/{eventId}`（operationId: `deleteEvent`）を呼ぶ。

   リクエスト

   | 場所 | パラメータ | 値 |
   | --- | --- | --- |
   | path | `eventId` | URL パラメータ `eventId` |

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 204 | MSG-016 をトーストで表示する<br>SCR-001 イベント一覧へ遷移する |
   | 401 | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |

   | 404 | MSG-021 をトーストで表示する<br>SCR-001 イベント一覧へ遷移する |
   | 409 | No.38 を閉じる<br>MSG-019 を No.7 に表示する |
   | 上記以外 | No.38 を閉じる<br>MSG-022 を No.7 に表示する |

### A11. 離脱の確認で「キャンセル」ボタン押下

### A12. 離脱の確認で「離れる」ボタン押下

### A13. ブラウザの戻る・再読み込み・タブを閉じる

1. 入力内容に変更があるとき（変更があるかどうかの基準は、A1 の手順 1 と同じ）、ブラウザ標準の離脱確認ダイアログを表示する（文言はブラウザが決めるため指定できない）。
2. アクションの処理による遷移（保存・削除に成功したあとの遷移、401 のときのログイン画面への遷移、404 のときの一覧への遷移など）では、入力内容に変更があっても離脱確認を表示しない。
