## 5. 初期表示時の処理

1. フォームの代わりにスピナーを表示する。
2. `GET /me`（operationId: `getMe`）を呼ぶ。

   リクエスト: なし

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | `id` と `role` を画面の表示条件の判定用に保持する |
   | 401 | SCR-005 ログインへ遷移する（`redirect` に現在の URL を渡す） |
   | 上記以外 | スピナーを消す（共通ヘッダーと No.1、No.2、No.6 だけを表示し、入力項目とボタンは表示しない）<br>MSG-022 を No.6 に表示して終了する |

3. `role` が `member` のとき、MSG-020 をトーストで表示する。
4. `role` が `member` のとき、SCR-001 イベント一覧へ遷移して終了する。
5. `GET /categories`（operationId: `listCategories`）を呼ぶ。

   リクエスト: なし

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | `items[]` を No.14 の選択肢にする（表示は `name`、値は `id`。先頭に「選択してください」を置く） |
   | 401 | SCR-005 ログインへ遷移する（`redirect` に現在の URL を渡す） |
   | 上記以外 | スピナーを消す（共通ヘッダーと No.1、No.2、No.6 だけを表示し、入力項目とボタンは表示しない）<br>MSG-022 を No.6 に表示して終了する |

### A1. 「← 一覧へ戻る」リンク押下

1. 入力内容に変更がないとき（どの入力項目も、基準の値と同じとき。基準は、初期表示のときの値。下書き保存に成功したあとは、最後に成功した保存を始めたとき（ボタンを押したとき）の入力欄の値）、No.1 の `href` へ遷移して終了する。
2. No.49 を表示する。

### A2. No.8 からフォーカスが外れる

1. バリデーションを行う。

   | No | 項目 | 条件 | メッセージ | 表示先 |
   | --- | --- | --- | --- | --- |
   | 8 | タイトル | 必須 | MSG-001（v1: タイトル） | No.9 |
   | 8 | タイトル | 2 文字以上 | MSG-003（v1: タイトル、v2: 2） | No.9 |
   | 8 | タイトル | 50 文字以内 | MSG-004（v1: タイトル、v2: 50） | No.9 |
   | 8 | タイトル | 使える文字: 全角文字（ひらがな・カタカナ・漢字・英数字・記号）、半角英数字、半角記号 | MSG-005（v1: タイトル） | No.9 |

2. エラーがあれば、No.9 に最初の 1 件を表示する。なければ No.9 を非表示にする。

### A3. 開催形式の選択を変更

1. 「会場」を選んだとき、No.21 を表示する。
2. 「会場」を選んだとき、No.24 と No.25 を非表示にする。
3. 「オンライン」を選んだとき、No.24 を表示する。
4. 「オンライン」を選んだとき、No.21 と No.22 を非表示にする。
5. 非表示にした項目の入力済みの値は残す（選び直したときに戻せるようにするため）。
6. 選び直して表示した項目のエラー表示は、非表示のままにする（その項目を次にチェックするまで出さない）。

### A7. 「公開する」／「更新する」ボタン押下

2. No.6 を非表示にする。
3. No.41〜43 を非活性にする。
4. `PUT /events/{eventId}`（operationId: `updateEvent`）を呼ぶ。

   リクエスト

   | 場所 | パラメータ | 値 |
   | --- | --- | --- |
   | path | `eventId` | URL パラメータ `eventId` |
   | body | `title`〜`tags` | A6 の手順 8 と同じ |
   | body | `status` | 保持した `status` が `draft` なら固定値 `published`、それ以外は保持した `status` |

   レスポンス

   | ステータス | 処理 |
