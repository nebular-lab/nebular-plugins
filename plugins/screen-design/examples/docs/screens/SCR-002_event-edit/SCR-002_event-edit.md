## 1. 概要

すでにあるイベントの内容を直す画面。下書きを公開する、公開中の内容を更新する、イベントを削除する、のどれかを行う。

## 2. クエリパラメータ

なし

## 3. 権限

| 利用者の種類 | 閲覧 | 備考 |
| --- | --- | --- |
| admin | ○ | すべてのイベントを編集・削除できる |
| organizer | ○ | 編集・削除は自分が主催のイベントだけ。他の人のイベントを開くと API が 403 を返す |
| member | × | MSG-020 をトーストで表示して SCR-001 イベント一覧へ遷移する |
| 未ログイン | × | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |

## 5. 初期表示時の処理

1. フォームの代わりにスピナーを表示する。
2. `GET /me`（operationId: `getMe`）を呼ぶ。

   リクエスト: なし

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | `id` と `role` を画面の表示条件の判定用に保持する |
   | 401 | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |
   | 上記以外 | スピナーを消す（No.1〜6 と No.10 だけを表示し、入力項目とボタンは表示しない）<br>MSG-022 を No.10 に表示して終了する |

3. `role` が `member` のとき、MSG-020 をトーストで表示する。
4. `role` が `member` のとき、SCR-001 イベント一覧へ遷移して終了する。
5. `GET /categories`（operationId: `listCategories`）を呼ぶ。

   リクエスト: なし

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | `items[]` を No.18 の選択肢にする（表示は `name`、値は `id`。先頭に「選択してください」を置く） |
   | 401 | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |
   | 上記以外 | スピナーを消す（No.1〜6 と No.10 だけを表示し、入力項目とボタンは表示しない）<br>MSG-022 を No.10 に表示して終了する |

6. `GET /events/{eventId}`（operationId: `getEvent`）を呼ぶ。

   リクエスト

   | 場所 | パラメータ | 値 |
   | --- | --- | --- |
   | path | `eventId` | URL パラメータ `eventId` |

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | 各入力項目に、画面項目の表の初期値を入れる<br>`status` を No.7 に、`organizerName` を No.9 に表示する<br>`version`、`status`、`participantCount`、`organizerId` を保持する<br>スピナーを消す<br>フォームを表示する |
   | 401 | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |
   | 403 | MSG-020 をトーストで表示する<br>SCR-001 イベント一覧へ遷移する |
   | 404 | MSG-021 をトーストで表示する<br>SCR-001 イベント一覧へ遷移する |
   | 上記以外 | スピナーを消す（No.1〜6 と No.10 だけを表示し、入力項目とボタンは表示しない）<br>MSG-022 を No.10 に表示する |

### A1. メニューのボタン押下

1. 全画面で共通のメニューを開く（メニューに並べる内容は TBD）。

### A2. 「← 一覧へ戻る」リンク押下

1. 入力内容に変更がないとき（どの入力項目も、基準の値と同じとき。基準は、初期表示のときの値。下書き保存に成功したあとは、最後に成功した保存を始めたとき（ボタンを押したとき）の入力欄の値）、SCR-001 イベント一覧へ遷移して終了する。
2. No.53 を表示する。

### A3. No.12 からフォーカスが外れる

1. バリデーションを行う。

   | No | 項目 | 条件 | メッセージ | 表示先 |
   | --- | --- | --- | --- | --- |
   | 12 | タイトル | 必須 | MSG-001（v1: タイトル） | No.13 |
   | 12 | タイトル | 2 文字以上 | MSG-003（v1: タイトル、v2: 2） | No.13 |
   | 12 | タイトル | 50 文字以内 | MSG-004（v1: タイトル、v2: 50） | No.13 |
   | 12 | タイトル | 使える文字: 全角文字（ひらがな・カタカナ・漢字・英数字・記号）、半角英数字、半角記号 | MSG-005（v1: タイトル） | No.13 |

2. エラーがあれば、No.13 に最初の 1 件を表示する。なければ No.13 を非表示にする。

### A4. 開催形式の選択を変更

1. 「会場」を選んだとき、No.25 を表示する。
2. 「会場」を選んだとき、No.28 と No.29 を非表示にする。
3. 「オンライン」を選んだとき、No.28 を表示する。
4. 「オンライン」を選んだとき、No.25 と No.26 を非表示にする。
5. 非表示にした項目の入力済みの値は残す（選び直したときに戻せるようにするため）。
6. 選び直して表示した項目のエラー表示は、非表示のままにする（その項目を次にチェックするまで出さない）。
