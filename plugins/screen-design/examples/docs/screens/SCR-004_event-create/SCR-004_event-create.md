## 5. 初期表示時の処理

1. フォームの代わりにスピナーを表示する。
2. `GET /me`（operationId: `getMe`）を呼ぶ。

   リクエスト: なし

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | `role` を保持する（手順 3・4 の判定に使う） |
   | 401 | SCR-005 ログインへ遷移する（`redirect` に現在の URL を渡す） |
   | 上記以外 | スピナーを消す（共通ヘッダーと No.1〜3 だけを表示し、入力項目とボタンは表示しない）<br>MSG-022 を No.3 に表示して終了する |

3. `role` が `member` のとき、MSG-020 をトーストで表示する。
4. `role` が `member` のとき、SCR-001 イベント一覧へ遷移して終了する。
5. `GET /categories`（operationId: `listCategories`）を呼ぶ。

   リクエスト: なし

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | `items[]` を No.11 の選択肢にする（表示は `name`、値は `id`。先頭に「選択してください」を置く） |
   | 401 | SCR-005 ログインへ遷移する（`redirect` に現在の URL を渡す） |
   | 上記以外 | スピナーを消す（共通ヘッダーと No.1〜3 だけを表示し、入力項目とボタンは表示しない）<br>MSG-022 を No.3 に表示して終了する |

6. 各入力項目を、画面項目の表の `value`（ラジオボタンとチェックボックスは `checked`）のとおりにする。
7. スピナーを消す。
8. フォームを表示する。

### A1. 「← 一覧へ戻る」リンク押下

1. 入力内容に変更がないとき（どの入力項目も、初期表示のときの値と同じとき）、No.1 の `href` へ遷移して終了する。
2. No.39 を表示する。

### A2. No.5 からフォーカスが外れる

1. バリデーションを行う。

   | No | 項目 | 条件 | メッセージ | 表示先 |
   | --- | --- | --- | --- | --- |
   | 5 | タイトル | 必須 | MSG-001（v1: タイトル） | No.6 |
   | 5 | タイトル | 2 文字以上 | MSG-003（v1: タイトル、v2: 2） | No.6 |
   | 5 | タイトル | 50 文字以内 | MSG-004（v1: タイトル、v2: 50） | No.6 |
   | 5 | タイトル | 使える文字: 全角文字（ひらがな・カタカナ・漢字・英数字・記号）、半角英数字、半角記号 | MSG-005（v1: タイトル） | No.6 |

2. エラーがあれば、No.6 に最初の 1 件を表示する。なければ No.6 を非表示にする。

### A3. 開催形式の選択を変更

1. 「会場」を選んだとき、No.18 を表示する。
2. 「会場」を選んだとき、No.21 と No.22 を非表示にする。
3. 「オンライン」を選んだとき、No.21 を表示する。
4. 「オンライン」を選んだとき、No.18 と No.19 を非表示にする。
5. 非表示にした項目の入力済みの値は残す（選び直したときに戻せるようにするため）。
6. 選び直して表示した項目のエラー表示は、非表示のままにする（その項目を次にチェックするまで出さない）。

### A4. No.27 に入力

### A5. タグの選択を変更

### A10. ブラウザの戻る・再読み込み・タブを閉じる

1. 入力内容に変更があるとき（変更があるかどうかの基準は、A1 の手順 1 と同じ）、ブラウザ標準の離脱確認ダイアログを表示する（文言はブラウザが決めるため指定できない）。
2. アクションの処理による遷移（保存・削除に成功したあとの遷移、401 のときのログイン画面への遷移、404 のときの一覧への遷移など）では、入力内容に変更があっても離脱確認を表示しない。
