## 1. 概要

イベントをキーワードとステータスで探す画面。タイトルからイベントの詳細に進む。admin と organizer は、ここからイベントの作成にも進む。

## 2. クエリパラメータ

| パラメータ | 値 | 省略したとき | 用途 |
| --- | --- | --- | --- |
| `keyword` | 文字列 | 空 | キーワードの初期値と、検索の条件（`GET /events` の `keyword`）。前後の空白は除いて使う。空白を除いて空になるときは、省略したときと同じに扱う |
| `status` | `published`、`draft`、`closed` | 「すべて」のタブを選ぶ | 選ぶタブと、検索の条件（`GET /events` の `status`）。この 3 つと完全に一致しない値のとき、または `GET /me` の `role` が `member` で `draft` のときは、省略したときと同じに扱う |
| `page` | 1 以上の整数（半角数字だけで、先頭が 0 でないもの） | 1 | 表示するページ（`GET /events` の `page`）。1 以上の整数でない値のときは、省略したときと同じに扱う。総ページ数を超える値は、そのまま使う（一覧は 0 件になり、データなしの表示とページ送りを表示する） |

省略したときと同じに扱う値が URL に付いていたときは、初期表示時の処理で URL から取り除く（「5. 初期表示時の処理」の手順 3）。

## 5. 初期表示時の処理

1. URL クエリ `keyword` を No.9 に入れる（前後の空白は除く）。
2. `GET /me`（operationId: `getMe`）を呼ぶ。

   リクエスト: なし

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | `name` を No.4 に表示する<br>`id` と `role` を画面の表示条件の判定用に保持する |
   | 401 | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |
   | 上記以外 | MSG-023 を No.37 に表示して終了する（No.8、No.9、No.11、No.12 は表示したままにする。No.12 は「下書き」を表示せず、「すべて」を選んだ状態にする） |

3. URL クエリを整える（ブラウザの履歴を置き換える）。「2. クエリパラメータ」で省略したときと同じに扱う値のパラメータ（`keyword`、`status`、`page`）は消し、`keyword` は前後の空白を除いた値にする。変えるところがなければ、何もしない。
4. URL クエリ `status` に対応するタブを No.12 で選ぶ。`status` がなければ「すべて」を選ぶ。
5. No.7、No.17、No.28、No.36、No.37 を非表示にする。
6. 一覧の位置に No.35 を表示する。
7. `GET /events`（operationId: `listEvents`）を呼ぶ。

   リクエスト

   | 場所 | パラメータ | 値 |
   | --- | --- | --- |
   | query | `keyword` | URL クエリ `keyword`（なければ送らない） |
   | query | `status` | URL クエリ `status`（なければ送らない） |
   | query | `page` | URL クエリ `page`（なければ固定値 1） |
   | query | `perPage` | 固定値 20 |

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | No.35 を非表示にする<br>`items` が 0 件なら No.36 を表示する<br>`items` が 1 件以上なら `items[]` を No.17 に入れて表示する<br>`total` が 1 件以上なら `total`、`page`、`perPage` から No.28 を表示する |
   | 400 | No.35 を非表示にする<br>MSG-024 を No.7 に表示する |
   | 401 | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |
   | 上記以外 | No.35 を非表示にする<br>MSG-023 を No.37 に表示する |

### A1. 「イベントを作成」ボタン押下

1. SCR-004 イベント作成へ遷移する。

### A2. 「検索」ボタン押下

1. バリデーションを行う。

   | No | 項目 | 条件 | メッセージ | 表示先 |
   | --- | --- | --- | --- | --- |
   | 9 | キーワード | 50 文字以内 | MSG-004（v1: キーワード、v2: 50） | No.10 |
   | 9 | キーワード | 使える文字: 全角文字（ひらがな・カタカナ・漢字・英数字・記号）、半角英数字、半角記号 | MSG-005（v1: キーワード） | No.10 |

2. エラーがあれば、No.10 に最初の 1 件を表示して終了する。なければ No.10 を非表示にする。
3. No.11 を非活性にする。
4. URL クエリの `keyword` を No.9 の入力値（前後の空白を除く。空なら `keyword` を消す）に、`page` を 1 に書き換える（ブラウザの履歴に追加する）。`status` は変えない。
5. `GET /me` が失敗していたなら「5. 初期表示時の処理」の手順 2〜7 をやり直す。なければ、手順 5〜7 と同じく `GET /events` を呼ぶ（`keyword` と `page` は手順 4 で書き換えた値になる）。
6. No.11 の非活性を解除する（手順 5 が途中で終了したときも解除する）。

### A3. タブの切り替え

1. 選んだタブを選択状態にする。
2. URL クエリの `status` を選んだタブの値（「公開中」は `published`、「下書き」は `draft`、「終了」は `closed`。「すべて」なら `status` を消す）に、`page` を 1 に書き換える（ブラウザの履歴に追加する）。`keyword` は変えない（No.9 に入力途中の値があっても、検索には使わない）。
3. No.9 を、URL クエリ `keyword` の値（前後の空白を除く）に戻す（なければ空にする。入力途中の値は捨てる）。
4. No.10 を非表示にする。
5. `GET /me` が失敗していたなら「5. 初期表示時の処理」の手順 2〜7 をやり直す。なければ、手順 5〜7 と同じく `GET /events` を呼ぶ（`status` と `page` は手順 2 で書き換えた値になる）。

### A4. タイトルのリンク押下

1. SCR-003 イベント詳細へ遷移する（`eventId` に、押した行の `GET /events` の `items[].id` を渡す）。

### A5. 「オンライン会場」リンク押下

1. 押した行の `GET /events` の `items[].onlineUrl` を別タブで開く。

### A6. 「前へ」ボタン押下

1. URL クエリの `page` を 1 減らす（ブラウザの履歴に追加する）。
2. No.9 を、URL クエリ `keyword` の値（前後の空白を除く）に戻す（なければ空にする。入力途中の値は捨てる）。
3. No.10 を非表示にする。
4. 「5. 初期表示時の処理」の手順 5〜7 と同じく `GET /events` を呼ぶ（`page` は手順 1 で書き換えた値になる）。
5. 画面の一番上までスクロールする。

### A7. 「次へ」ボタン押下

1. URL クエリの `page`（なければ 1）を 1 増やす（ブラウザの履歴に追加する）。
2. No.9 を、URL クエリ `keyword` の値（前後の空白を除く）に戻す（なければ空にする。入力途中の値は捨てる）。
3. No.10 を非表示にする。
4. 「5. 初期表示時の処理」の手順 5〜7 と同じく `GET /events` を呼ぶ（`page` は手順 1 で書き換えた値になる）。
5. 画面の一番上までスクロールする。

### A8. ヘルプのリンク押下

1. ヘルプ（URL は TBD）を別タブで開く。

### A9. 「再読み込み」ボタン押下

1. `GET /me` が失敗していたなら「5. 初期表示時の処理」の手順 2〜7 をやり直す。なければ手順 5〜7 と同じく `GET /events` を呼ぶ。

### A10. ブラウザの戻る・進むで、この画面の URL クエリが変わる

1. 「5. 初期表示時の処理」の手順 1 と同じく、URL クエリ `keyword` を No.9 に入れる。
2. No.10 を非表示にする。
3. `GET /me` が失敗していたなら「5. 初期表示時の処理」の手順 2〜7 をやり直す。なければ手順 3〜7 をやり直す（変わったあとの URL クエリで、タブを選び直し、`GET /events` を呼ぶ）。
