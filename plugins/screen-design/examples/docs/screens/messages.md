# メッセージ一覧

全画面で共通のメッセージ。画面設計書からは ID で参照する。文言の中の `{v1}`、`{v2}` は変数。参照する側で、それぞれに入れる値を指定する（`MSG-004（v1: タイトル、v2: 50）`）。

| ID | 種別 | 文言 |
| --- | --- | --- |
| MSG-001 | エラー | {v1}を入力してください |
| MSG-002 | エラー | {v1}を選択してください |
| MSG-003 | エラー | {v1}は {v2} 文字以上で入力してください |
| MSG-004 | エラー | {v1}は {v2} 文字以内で入力してください |
| MSG-005 | エラー | {v1}に使えない文字（絵文字など）が含まれています |
| MSG-006 | エラー | {v1}は半角英数字と記号で入力してください |
| MSG-007 | エラー | {v1}は https:// で始まる形式で入力してください |
| MSG-008 | エラー | {v1}は今日以降の日付を入力してください |
| MSG-009 | エラー | {v1}は {v2}〜{v3} で入力してください |
| MSG-010 | エラー | 定員は現在の参加者数（{v1} 人）以上にしてください |
| MSG-011 | エラー | {v1}は {v2} つまで選べます |
| MSG-012 | 確認 | 入力内容が保存されていません。このページを離れますか？ |
| MSG-013 | 完了 | 下書きを保存しました |
| MSG-014 | 完了 | イベントを公開しました |
| MSG-015 | 完了 | イベントを更新しました |
| MSG-016 | 完了 | イベントを削除しました |
| MSG-017 | 確認 | イベントを削除しますか？<br>「{v1}」を削除します。この操作は取り消せません。 |
| MSG-018 | エラー | 他の人が先に更新しました。画面を再読み込みしてから、もう一度保存してください |
| MSG-019 | エラー | 参加者がいるイベントは削除できません |
| MSG-020 | エラー | イベントを作成・編集する権限がありません |
| MSG-021 | エラー | イベントが見つかりません |
| MSG-022 | エラー | 通信に失敗しました。時間をおいてもう一度お試しください |
| MSG-023 | エラー | イベントを読み込めませんでした。 |
| MSG-024 | エラー | 検索条件が正しくありません。条件を変えて検索してください |
| MSG-025 | エラー | このイベントを表示する権限がありません |
| MSG-026 | エラー | {v1}はメールアドレスの形式で入力してください |
| MSG-027 | エラー | メールアドレスまたはパスワードが正しくありません |
