# HDR-002 ログイン前のヘッダー

| 項目 | 内容 |
| --- | --- |
| ヘッダー ID | HDR-002 |
| ヘッダー名 | ログイン前のヘッダー |
| 使う画面 | ログインしていなくても見られる画面（どの画面で使っているかは、[overview.md](../overview.md) の画面一覧を見る） |
| ワイヤーフレーム | [HDR-002_public-header.html](HDR-002_public-header.html) |
| 更新日 | 2026-10-11 |

## 1. 概要

ログインしていない利用者にも見せる画面の、いちばん上に置くヘッダー。ログイン画面へ進むリンクを置く。

## 2. 変数

ヘッダーを置く画面が、設計書の冒頭の表の「共通ヘッダー」で値を指定する。

| 変数 | 内容 |
| --- | --- |
| `{v1}` | 「ログイン」のリンクを表示するかどうか。`表示する` か `表示しない`（ログイン画面そのものでは `表示しない`） |
