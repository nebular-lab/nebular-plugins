## 1. 概要

イベントの内容を確かめる画面。編集できる利用者は、ここからイベントの編集に進むか、イベントを削除する。

## 2. クエリパラメータ

なし

## 3. 権限

| 利用者の種類 | 閲覧 | 備考 |
| --- | --- | --- |
| admin | ○ | すべてのイベントを表示・編集・削除できる |
| organizer | ○ | 編集・削除は自分が主催のイベントだけ |
| member | ○ | 「編集」と「削除」は表示しない。下書きのイベントを開くと API が 403 を返す |
| 未ログイン | × | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |

## 5. 初期表示時の処理

1. No.4〜22 の代わりに No.23 を表示する。
2. `GET /me`（operationId: `getMe`）を呼ぶ。

   リクエスト: なし

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | `id` と `role` を画面の表示条件の判定用に保持する |
   | 401 | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |
   | 上記以外 | No.23 を非表示にする<br>MSG-022 を No.3 に表示して終了する |

3. `GET /categories`（operationId: `listCategories`）を呼ぶ。

   リクエスト: なし

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | `items[]` を No.10 の表示用に保持する |
   | 401 | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |
   | 上記以外 | No.23 を非表示にする<br>MSG-022 を No.3 に表示して終了する |

4. `GET /events/{eventId}`（operationId: `getEvent`）を呼ぶ。

   リクエスト

   | 場所 | パラメータ | 値 |
   | --- | --- | --- |
   | path | `eventId` | URL パラメータ `eventId` |

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 200 | `organizerId` と `participantCount` を保持する<br>No.23 を非表示にする<br>No.4〜20 に、画面項目の表の表示内容を表示する<br>表示条件を満たすとき、No.21 と No.22 を表示する |
   | 401 | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |
   | 403 | MSG-025 をトーストで表示する<br>SCR-001 イベント一覧へ遷移する |
   | 404 | MSG-021 をトーストで表示する<br>SCR-001 イベント一覧へ遷移する |
   | 上記以外 | No.23 を非表示にする<br>MSG-022 を No.3 に表示する |

## 6. アクション

### アクション一覧

| ID | 操作 | 対象 | 概要 |
| --- | --- | --- | --- |
| A1 | 「← 一覧へ戻る」リンク押下 | No.2 | イベント一覧へ戻る |
| A2 | 「編集」ボタン押下 | No.21 | イベントの編集へ移る |
| A3 | 「削除」ボタン押下 | No.22 | 削除の確認を表示する |
| A4 | 削除の確認で「キャンセル」ボタン押下 | No.25 | 削除の確認を閉じる |
| A5 | 削除の確認で「削除する」ボタン押下 | No.26 | イベントを削除する |

### A1. 「← 一覧へ戻る」リンク押下

1. SCR-001 イベント一覧へ遷移する。

### A2. 「編集」ボタン押下

1. SCR-002 イベント編集へ遷移する（`eventId` に URL パラメータ `eventId` を渡す）。

### A3. 「削除」ボタン押下

1. No.24 を表示する。

### A4. 削除の確認で「キャンセル」ボタン押下

1. No.24 を閉じる。

### A5. 削除の確認で「削除する」ボタン押下

1. No.3 を非表示にする。
2. No.26 を非活性にする。
3. `DELETE /events/{eventId}`（operationId: `deleteEvent`）を呼ぶ。

   リクエスト

   | 場所 | パラメータ | 値 |
   | --- | --- | --- |
   | path | `eventId` | URL パラメータ `eventId` |

   レスポンス

   | ステータス | 処理 |
   | --- | --- |
   | 204 | MSG-016 をトーストで表示する<br>SCR-001 イベント一覧へ遷移する |
   | 401 | ログイン画面（`/login?redirect=` に現在の URL）へ遷移する |
   | 403 | No.24 を閉じる<br>MSG-020 をトーストで表示する |
   | 404 | MSG-021 をトーストで表示する<br>SCR-001 イベント一覧へ遷移する |
   | 409 | No.24 を閉じる<br>MSG-019 を No.3 に表示する |
   | 上記以外 | No.24 を閉じる<br>MSG-022 を No.3 に表示する |

4. 画面に残っているとき、No.26 の非活性を解除する。
